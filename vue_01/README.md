# 🚀 Curso Vue.js - Nivel 3

Bienvenido a este repositorio de aprendizaje de Vue.js. Aquí encontrarás los primeros pasos y ejercicios prácticos desarrollados durante el curso, demostrando conceptos fundamentales y técnicas modernas de desarrollo con Vue 3.

---

## 📂 Contenido del Repositorio

Este repositorio está organizado en dos partes principales, cada una enfocada en diferentes aspectos del aprendizaje de Vue.js.

### 1. Proyecto Vue 01 (Fundamentos)
> **Ubicación**: Raíz (`index.html`, `app.js`)

Este es el punto de entrada al mundo de Vue.js. Una aplicación sencilla pero poderosa que demuestra la reactividad básica y la manipulación del DOM.

**✨ Características Principales:**
- **Instalación CDN**: Uso de Vue.js directamente en el navegador sin herramientas de compilación complejas.
- **Data Binding**: Enlace bidireccional y reactivo de datos.
- **Lógica Condicional**: Renderizado de mensajes y tareas basado en condiciones aleatorias (`Math.random()`), simulando toma de decisiones dinámica.
- **Manejo de Eventos**: Interacciones básicas definidas en la instancia de la aplicación.

---

### 2. Ejercicio Profesional Moderno (Tarjeta de Perfil)
> **Ubicación**: Carpeta `exercise_01/`

Una aplicación más estructurada que simula un componente de interfaz de usuario profesional: una tarjeta de perfil personal ("About Me"). Este ejercicio pone en práctica un diseño más limpio y funcionalidades lógicas más avanzadas.

**✨ Características Principales:**
- **Diseño Moderno**: Estilizado con CSS personalizado (`style.css`) para una apariencia pulida y agradable.
- **Cálculo Dinámico**: Métodos para calcular datos en tiempo real (ej. predicción de edad futura).
- **Interpolación de Texto**: Visualización dinámica de datos personales (Nombre, Edad).
- **Binding de Atributos**: Enlaces dinámicos a atributos HTML como `href` y `target`.
- **Estructura Modular**: Separación clara de responsabilidades entre HTML, CSS y Lógica (JS).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Estilos personalizados y diseño responsivo.
- **Vue.js 3**: Framework progresivo de JavaScript (versión global via CDN).

## 🚀 Cómo Ejecutar

No es necesario instalar dependencias de Node.js. Simplemente:

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` (para el Proyecto 01) o `exercise_01/index.html` (para el Ejercicio Profesional) directamente en tu navegador web favorito (Chrome, Firefox, Edge).
3. ¡Disfruta explorando la reactividad de Vue!
